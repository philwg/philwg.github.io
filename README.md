## README – Commodore‑Style Welcome Page  

**Repository:** `github.com/philwg/philwg.github.io`  

---  

### 📄 Présentation  

Ce dépôt contient une petite page web statique qui reproduit l’esthétique des écrans **Commodore** des années 1980 : texte orange vif sur fond noir.  

- **Conforme aux standards HTML 5** (doctype, charset UTF‑8, attribut `lang`, balises sémantiques).  
- **CSS local uniquement** : aucune dépendance externe, aucune police ou image distante.  
- **Respect total de la vie privée** : aucune balise `<script>`, aucun cookie, aucune collecte de données, aucune requête réseau vers des tiers.  

Le projet est idéal pour :  

- Un point d’entrée minimaliste pour un site personnel.  
- Une démonstration de bonnes pratiques d’accessibilité et de confidentialité.  
- Un clin d’œil nostalgique aux premiers ordinateurs personnels.
